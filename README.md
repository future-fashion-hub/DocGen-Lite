# DocGen Lite

DocGen Lite — это легковесное консольное приложение, которое сканирует исходный код C/C++ и генерирует HTML-документацию на основе комментариев в стиле Doxygen (`///` и `/** */`).

## Возможности

- Рекурсивный поиск файлов `.cpp`, `.h`, `.hpp`, `.c`, `.cc`
- Извлечение классов, методов и полей
- Разбор тегов: `@param`, `@return`, `@author`, `@version`, `@see`, `@note`
- Генерация `index.html`, страниц классов и страниц файлов
- Поддержка UTF-8, включая комментарии на кириллице

## Требования для сборки

- CMake 3.10+
- Компилятор C++17 (GCC 7+, Clang 5+, MSVC 2017+)

## Сборка 

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
cd build
./docgen -i ../src -o ./docs
```

После выполнения откройте `build/docs/index.html` в браузере.

## Сторонние библиотеки

На текущем этапе внешние библиотеки не используются.
